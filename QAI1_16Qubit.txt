## 6. APPLYING THE HADAMARD GATE

### `for qubit in range(n):`

- Creates a for loop.
- `range(n)` generates numbers from 0 to 15.
- These numbers represent the indices of the 16 qubits.
- The loop accesses each qubit one by one.

### `qc.h(qubit)`

- Applies the Hadamard gate to the current qubit.
- The Hadamard gate is represented by the symbol H.
- It converts the initial state |0⟩ into an equal superposition of |0⟩ and |1⟩.
- This gives both possible measurement outcomes equal probability.

**Mathematical representation:**

H|0⟩ = (|0⟩ + |1⟩)/√2

Therefore:

- Probability of measuring 0 = 50%.
- Probability of measuring 1 = 50%.

Since the Hadamard gate is applied to all 16 qubits, all qubits enter an equal superposition.

# 16. IMPORTANT CONCEPTS RELATED TO THE AIM

## 1. What is Quantum Computing?

Quantum computing is a type of computing that uses principles of quantum mechanics to process information.

Traditional computers use bits, whereas quantum computers use qubits.

**Example:**
- Classical computer: Uses 0 and 1.
- Quantum computer: Uses qubits that can exist in superposition.

## 2. What is a Qubit?

A qubit (quantum bit) is the fundamental unit of quantum information.

A qubit can be represented mathematically as:

|ψ⟩ = α|0⟩ + β|1⟩

Where:

- α = Probability amplitude of state |0⟩.
- β = Probability amplitude of state |1⟩.
- |0⟩ and |1⟩ are computational basis states.

The probabilities are:

P(0) = |α|²

P(1) = |β|²

The total probability is:

|α|² + |β|² = 1

## 3. What is Superposition?

Superposition is a quantum mechanical principle in which a qubit can exist in a combination of the states |0⟩ and |1⟩.

For example:

|ψ⟩ = (|0⟩ + |1⟩)/√2

This represents equal superposition.

The probabilities are:

- P(0) = 50%
- P(1) = 50%

**Importance in this practical:**

Superposition is used to create equal probability measurement outcomes, which helps generate random binary values.

## 4. What is a Hadamard Gate?

The Hadamard gate is a single-qubit quantum gate used to create superposition.

Its matrix representation is:

H = 1/√2 ×

| 1  1 |  
| 1 -1 |

Its important transformations are:

H|0⟩ = (|0⟩ + |1⟩)/√2

H|1⟩ = (|0⟩ - |1⟩)/√2

**Importance:**

In this practical, the Hadamard gate is applied to all 16 qubits to create equal superposition.

## 5. What is Quantum Measurement?

Quantum measurement is the process of observing a quantum system to obtain a classical result.

Before measurement, the qubit may be in superposition.

After measurement, it produces a definite result:

- 0
- 1

**Importance:**

Measurement converts the quantum state into binary values that can be used to generate a random number.

## 6. What is Quantum State Collapse?

Quantum state collapse refers to the transition from a superposition state to a definite measurement outcome.

For example:

Before measurement:

(|0⟩ + |1⟩)/√2

After measurement:

Either |0⟩ or |1⟩.

The result is probabilistic.

## 7. What is Quantum Random Number Generation (QRNG)?

QRNG stands for Quantum Random Number Generation.

It is a technique used to generate random numbers using quantum mechanical phenomena.

Unlike conventional random number generators, which generally use mathematical algorithms, QRNG uses quantum measurement outcomes.

**Working:**

1. Initialize qubits.
2. Apply Hadamard gates.
3. Create superposition.
4. Measure the qubits.
5. Obtain binary outcomes.
6. Combine the outcomes to generate a random number.

## 8. What is Classical Random Number Generation?

Classical random number generation generally uses mathematical algorithms to produce random-looking values.

For example, Python's `random` module generates pseudorandom numbers.

These numbers are produced using deterministic algorithms and an initial value called a seed.

**Difference between QRNG and Classical RNG:**

| Quantum RNG | Classical RNG |
|---|---|
| Uses quantum phenomena. | Uses mathematical algorithms. |
| Uses quantum measurement. | Uses computational methods. |
| Can generate true physical randomness with suitable quantum hardware. | Usually generates pseudorandom values. |
| Requires a quantum source or suitable quantum hardware for physical randomness. | Can run on ordinary computers. |

**Important:** This practical uses `StatevectorSampler`, which simulates quantum measurement using classical computation. Therefore, it demonstrates the QRNG principle but does not obtain physical quantum randomness from real quantum hardware.

## 9. What is a Statevector?

A statevector is a mathematical representation of the complete quantum state of a system.

For one qubit, the statevector contains two complex amplitudes.

For 16 qubits, the statevector contains:

2¹⁶ = 65,536 amplitudes.

Each amplitude represents a computational basis state.

**Importance:**

Statevector simulation allows us to calculate the quantum state and simulate measurement probabilities.

## 10. What is a Quantum Gate?

A quantum gate is an operation that changes the state of one or more qubits.

Examples:

| Quantum Gate | Purpose |
|---|---|
| X Gate | Flips the qubit state from 0 to 1 or 1 to 0. |
| Y Gate | Performs a quantum state rotation around the Y-axis. |
| Z Gate | Changes the phase of the quantum state. |
| H Gate | Creates superposition. |
| CNOT Gate | Performs a controlled-NOT operation on two qubits. |
| S Gate | Applies a phase shift of π/2. |
| T Gate | Applies a phase shift of π/4. |

## 11. What is Entanglement?

Quantum entanglement is a phenomenon in which two or more qubits become correlated so that their joint quantum state cannot be described independently.

For example:

(|00⟩ + |11⟩)/√2

If the first qubit is measured as 0, the second will also be 0. If the first is measured as 1, the second will also be 1.

**Is entanglement used in this practical?**

No. This practical uses Hadamard gates independently on all 16 qubits. No entangling gates are applied.

## 12. What is Binary Number System?

The binary number system is a number system with base 2.

It uses only two digits:

- 0
- 1

Each position represents a power of 2.

Example:

Binary = 1010

Decimal = 10

**Importance:**

Quantum measurement produces binary outcomes, which are combined to form a binary random number.

## 13. What is Decimal Number System?

The decimal number system is a number system with base 10.

It uses digits from 0 to 9.

In this practical, the generated binary number is converted into decimal using Python's `int()` function.

## 14. What is a Random Number Generator?

A Random Number Generator (RNG) is a system that generates numbers that appear unpredictable.

There are two major categories:

1. Pseudorandom Number Generator (PRNG).
2. True Random Number Generator (TRNG).

QRNG is a quantum-based approach to generating physical random numbers.

## 15. Applications of QRNG

QRNG is useful in several fields:

1. **Cryptography:** Generating random keys for secure communication.
2. **Cybersecurity:** Generating unpredictable security tokens.
3. **Scientific Research:** Supporting random sampling and experiments.
4. **Simulation:** Generating random values for probabilistic simulations.
5. **Gaming:** Generating unpredictable outcomes.
6. **Statistical Sampling:** Supporting randomized sampling methods.
